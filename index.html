NVIDIA, SME lending

GPU-accelerated fraud detection

Organised fraud in small-business lending hides in plain sight: each fake account looks normal on its own, so I look at the network instead. Real fraud data is private, so I built a generator for synthetic fraud graphs. At a realistic 1% fraud rate, a graph model found 2.7 times more fraud than a gradient-boosted baseline given the same information. At NVIDIA, that idea runs as a GPU pipeline pairing graph models with XGBoost, with agents reading streaming lending data so nobody has to hand-update rules.

Applied research

Quantum error correction with LLMs

Quantum computers make errors constantly, and a decoder has to guess which qubits went wrong. I had LLMs work alongside numerical optimisers to re-weight an MWPM decoder's matching graph, learning from the cases it got wrong. I report the two results separately, because simulation flatters.

0.74%lower error, Google hardware

I don't trust a model until it beats a boring one.

Most of the job is checking my own work. A model can score well and still be learning the wrong thing. So I start with the dullest baseline I can find, and anything fancier has to beat it by enough to matter. If a graph neural net can't outdo gradient boosting on flat features, the graph isn't adding anything, and I'd rather find that out myself than hear it from someone else.
